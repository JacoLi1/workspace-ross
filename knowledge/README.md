# Knowledge Directory

This directory contains personal learning notes, experience summaries, and reference materials for this digital employee.

## Purpose

- **Learning Notes**: Course notes, tutorials, book summaries
- **Experience**: Lessons learned, patterns discovered, best practices
- **Research**: Industry analysis, competitive research, technology deep-dives
- **Reference**: Useful code snippets, templates, checklists

## Important

- This is **personal knowledge**, not project deliverables.
- Project formal outputs go to the project repository or `members/` in the organization repo.
- Keep organized with clear file names and subdirectories as needed.
- Consider adding an `INDEX.md` to catalog key documents.

## Structure Suggestions

```
knowledge/
├── INDEX.md                    # Catalog of important notes
├── learning-notes/             # Structured learning summaries
│   ├── course-xxx.md
│   └── book-xxx.md
├── patterns/                   # Reusable patterns and templates
├── experiences/                # Retrospectives and lessons
└── references/                 # Cheat sheets, quick refs
```

Update this README if you develop a stable structure.
